# safari-bookmarks-from-chrome

Safari のブックマークを、Google Chrome のブックマークと同じ内容に置き換える AppleScript です（macOS 用）。

Safari の「ファイル > ブラウザから読み込む > Google Chrome」で読み込んでも、Safari にもともとあったブックマークは消えずに残ります。Chrome と同じ内容にそろえるには、先に Safari のブックマークを手で消す必要があります。

このスクリプトは、その「消す」と「読み込む」をまとめて行います。

> [!WARNING]
> 実行すると、Safari のブックマークはすべて消えます。iCloud で同期している場合は、iPhone や iPad の Safari からも消えます。
> 実行する前に、Safari の「ファイル > ブラウズデータをファイルに書き出す…」でバックアップを取ってください。

## 処理の流れ

最初の画面で「実行する」を選ぶと、次の順に進みます。

1. Safari の「ブックマークを編集」の画面で、ブックマークをすべて消す。「お気に入り」と「タブグループのお気に入り」の枠は残し、中身だけを消す
2. Chrome を終了する。Chrome が起動したままだと、読み込みの画面の「読み込む」ボタンが押せないため
3. 「ファイル > ブラウザから読み込む > Google Chrome」で、ブックマークだけを読み込む
4. 実行する前に Chrome が起動していた場合は、Chrome を起動し直す

「確認だけ」を選んだ場合は、消す対象を一覧にして選ぶところまでで終わります。ブックマークを消すことも、Chrome を終了することもしません。

## 動作環境

- **日本語の macOS 専用**です。スクリプトは、メニューの項目を日本語の名前（「ファイル」「ブラウザから読み込む」「読み込む」など）で探します
- Safari のメニューやボタンを、画面操作（System Events）で順に押していく方式です。Safari の画面の文言や構成が変わると、動かなくなるおそれがあります
- macOS 27.2.1、Safari 27.2 で動くことを確認しています

## 使い方

1. スクリプトエディタに「アクセシビリティ」の許可を与える（「システム設定 > プライバシーとセキュリティ > アクセシビリティ」）
2. Safari を起動して、ウインドウを1つ開いておく
3. `safari-bookmarks-from-chrome.applescript` をスクリプトエディタで開いて、実行する
4. 最初の画面で「確認だけ」か「実行する」を選ぶ
5. 終わるまで、マウスやキーボードには触らない

手順2で Safari を閉じたままにしても、スクリプトが Safari を起動します。ただし、起動したばかりの Safari ではメニューの準備が間に合わず、途中で止まるかもしれません（未検証）。

終わったときは、途中で止まった場合も含めて、経過ログがクリップボードにコピーされます。うまくいかなかったときの原因調べに使えます。

### 設定

次の項目は、スクリプトの先頭で変えられます。

- `importHistory`：`true` にすると、ブックマークに加えて履歴も読み込む（初期値は `false`）

## 既知の制限

- Chrome にプロファイルが複数ある場合も、プロファイルを選ぶ画面は出ません（プロファイルが2つある環境で確認）。どのプロファイルが読み込まれるかは Safari 側で決まり、その条件はわかっていません
- 「タブグループのお気に入り」の直下にあるフォルダは、タブグループごとに作られるもので、消せません。そのため、フォルダは残して中身だけを消します
