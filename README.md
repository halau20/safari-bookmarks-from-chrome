# safari-bookmarks-from-chrome

Google Chrome のブックマークで、macOS の Safari のブックマークを**置き換える** AppleScript です。

Safari の「ファイル > ブラウザから読み込む > Google Chrome」は、既存のブックマークに**追加**します。何度も読み込むと重複していくので、このスクリプトは先に Safari のブックマークを空にしてから読み込みます。

> [!WARNING]
> Safari のブックマークはすべて削除されます。iCloud で同期している場合は、iPhone・iPad の Safari からも消えます。
> 実行前に、Safari の「ファイル > ブラウズデータをファイルに書き出す…」でバックアップを取ってください。

## やること

「実行する」を選ぶと、次の順に進みます。

1. Safari の「ブックマークを編集」で、ブックマークをすべて削除する（「お気に入り」「タブグループのお気に入り」の枠は残し、中身だけ消す）
2. Chrome を終了する（Chrome が起動していると、読み込みの画面のボタンが押せないため）
3. 「ファイル > ブラウザから読み込む > Google Chrome」で、ブックマークだけを読み込む
4. 実行前に Chrome が起動していた場合は、Chrome を起動し直す

「確認だけ」を選ぶと、削除する対象の一覧を作るだけで、削除も Chrome の終了もしません。

## 動作環境

- **日本語の macOS 専用**です。メニュー名（「ファイル」「ブラウザから読み込む」「読み込む」など）を日本語で探しています
- Safari のメニューやボタンを画面操作（System Events）で順に押す方式です。Safari の画面の文言や構成が変わると、動かなくなる可能性があります
- 作者の環境では、2026年11月時点の macOS と Safari で動作を確認しています

## 使い方

1. スクリプトエディタに「アクセシビリティ」の許可を与える（システム設定 > プライバシーとセキュリティ > アクセシビリティ）
2. Safari を起動し、ウィンドウを1つ開いておく（閉じていても起動はしますが、起動直後はメニューの準備が間に合わず止まることがあります）
3. `safari-bookmarks-from-chrome.applescript` をスクリプトエディタで開いて実行する
4. 最初の画面で「確認だけ」か「実行する」を選ぶ
5. 動いている間は、マウスやキーボードに触らない

終わると（途中で止まった場合も）、経過ログがクリップボードにコピーされます。

### 設定

スクリプトの先頭で変えられます。

- `importHistory`：`true` にすると、ブックマークに加えて履歴も読み込みます（初期値は `false`）

## 既知の制限

- Chrome にプロファイルが複数あっても、選ぶ画面は出ません。どのプロファイルが読み込まれるかは Safari が決めていて、条件は確認できていません
- 「タブグループのお気に入り」の直下にあるフォルダは、各タブグループに付いたもので削除できないため、フォルダは残して中身だけ消します
